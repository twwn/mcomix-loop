- **urllib.request.pathname2url() is not the URI other programs use.** It escapes `()`, `,`, `+`, `=` and the like, which GLib (and so GNOME, KDE, GTK's recent list) leaves alone, and from Python 3.14 on returns `///tmp/x` for `/tmp/x`, so `'file://' + pathname2url(p)` is `file://///tmp/x`. Anything hashed or looked up by URI - the freedesktop thumbnail name, Gtk.RecentManager.remove_item() - misses. Use `Gio.File.new_for_path(p).get_uri()` (or `GLib.filename_to_uri`) and `Gio.File.new_for_uri(u).get_path()` back; both handle names that are not UTF-8 (a raw byte becomes `%E9`). Gtk.RecentManager.add_item() normalises what it is given, so adding with a bad URI still works and only removal shows the bug. Fixed in 17e322d9 (thumbnails) and 070c75b8 (recent list).
- **Python's mimetypes reads the system's mime.types files**, here /etc/mime.types and /etc/httpd/conf/mime.types, and the latter maps cbz, cb7 and cbt to application/x-cbr. Anything deciding a comic's type with mimetypes.guess_type() is machine-dependent. Use `Gio.content_type_guess(name, None)[0]` (name only, no I/O, case-insensitive; `Gio.content_type_get_mime_type()` for a MIME string on Windows). To ask a Gtk.FileFilter the chooser's own question without a chooser: build `Gio.FileInfo()` with set_display_name() and set_content_type() and call `ffilter.match(info)` (92c3f993). GTK 4's add_pattern() is case-sensitive; the MIME rule is what lets FILE.CBZ through.
- **Checking a thumbnail against GIO**: STATE/probes/thumb_store_gio.py makes a thumbnail of a zip and of a picture into `$XDG_CACHE_HOME/thumbnails/normal` and reads `thumbnail::path` and `thumbnail::is-valid` from Gio. GLib reads XDG_CACHE_HOME once per process, so it has to be set on the command line (`PROBE_CACHE=<dir> XDG_CACHE_HOME=<dir> ... pytest probe.py -s --rootdir=REPO`), not in os.environ from the test. GIO checks Thumb::URI and Thumb::MTime; at 7945e6ac it found neither thumbnail, at 8f46fa43 both, valid.
- **Stores MComix shares with the whole desktop** (at e394ccdd): the recently-used list (Gtk.RecentManager), the thumbnail cache under $XDG_CACHE_HOME/thumbnails, and the MIME database. Anything MComix does to them wholesale reaches every program: purge_items() emptied every program's recent files when MComix' own menu was cleared. Grep for purge_items, rmtree and os.remove near THUMBNAIL_PATH, and for anything counting get_items() as though it were MComix' own.
