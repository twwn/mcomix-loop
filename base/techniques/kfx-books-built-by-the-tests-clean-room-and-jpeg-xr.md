- **JPEG XR here**: jxrlib 1.4.4 (Arch package jxrlib) has JxrEncApp and JxrDecApp. `JxrEncApp -i in.bmp|in.pnm -o out.jxr -q 1` is lossless (BMP for colour; a grey TIFF fails with 150, grey PNM works). `JxrDecApp -i x.jxr -o y.tif` keeps the pixel format (L stays L); the input must end in .jxr (else exit 150). gdk-pixbuf here has no TIFF loader; MComix reads TIFF pages through Pillow, as DjVu's. Ubuntu: libjxr-tools (noble, resolute, universe). MSYS2: mingw-w64-ucrt-x86_64-jxrlib (JxrDecApp.exe, JxrEncApp.exe, libjpegxr.dll, libjxrglue.dll).
- **jxrlib under Wine**: fetch the package named in scratch/wine/msys/ucrt64.db (`tar -xOf ucrt64.db --wildcards '*jxrlib*/desc'`, the line after %FILENAME%) from repo.msys2.org/mingw/ucrt64/ into scratch/wine/msys/pkgs and `zstd -dcq ... | tar -x -C scratch/wine/msys/root` minus the .PKGINFO files; done at a42bb94b, so the JPEG XR tests run under Wine (32 passed).
